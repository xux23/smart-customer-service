# 智能客服工单系统

用户提一个问题，系统自动判断意图、查知识库回答；解决不了就自动创建工单，分配给对应部门转人工处理。

## 三个 Agent

| Agent | 职责 |
|---|---|
| 意图识别 Agent | 判断问题属于 售后 / 咨询 / 投诉 / 其他，输出置信度，低置信度兜底转人工 |
| 知识检索 Agent | 从知识库检索答案，命中直接回复；部分命中降级返回相似问题列表 |
| 工单处理 Agent | 自动创建工单、按意图分配部门，管理 待处理 → 处理中 → 已解决 的状态流转 |

## 项目亮点（面试讲解点）

1. **意图分类：Prompt 约束 + 四级兜底链** —— 约束 LLM 只输出 JSON；解析失败重试、再失败走关键词规则、LLM 不可用也不中断，兜底结果低置信度自动转人工。
2. **知识检索失败降级** —— 三级阈值路由：相似度足够直接回答；不够时返回 top3 相似问题让用户选；完全没命中就建工单。绝不"硬答"。
3. **工单状态机** —— 待处理 → 处理中 → 已解决，流转表集中定义，非法流转直接拒绝并记录审计事件。

## 技术栈

- Python 3.12 + **uv** 管理环境与依赖
- FastAPI 提供 REST 接口，另配命令行演示客户端
- OpenAI 兼容 API 接入大模型（智谱 GLM / DeepSeek / 通义均可，改配置即换），内置 Mock 模式离线可跑
- 知识检索：jieba 分词 + TF-IDF 余弦相似度（零外部依赖）
- 存储：SQLite（标准库 sqlite3，单文件零部署）
